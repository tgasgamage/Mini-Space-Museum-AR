# Mini Space Museum AR 🚀

## About the Project
Mini Space Museum AR is an interactive Augmented Reality project that allows users to explore space objects using their mobile phone cameras.

## Technologies Used
- HTML
- CSS
- JavaScript
- A-Frame
- AR.js

## Features
- Interactive space museum.
- 3D space objects.
- Augmented Reality experience.
- Mobile camera support.

## Team Project
Developed as a group project.
